Chuẩn bị file thế nào?
  • Nhanh nhất: kéo thẳng file .pptx vào. Web tự hiển thị slide và lấy ghi chú. Phông chữ và hiệu ứng có thể lệch đôi chút so với PowerPoint.
  • Chính xác nhất: kéo cả file PDF và file .pptx của cùng bộ slide. Slide hiển thị từ PDF, ghi chú lấy từ .pptx.
  • Google Slides: Tệp › Tải xuống › Microsoft PowerPoint (.pptx) (và PDF nếu muốn).
  • Keynote: File › Export To › PowerPoint (và PDF).
  • Ghi chú dạng .txt: mỗi slide một đoạn, ngăn cách bằng một dòng chỉ có ---.
